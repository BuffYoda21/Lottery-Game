# About
This game is the product of a school project cobbled together in just a few days and as a result, the source code may be very messy. I have no intention to maintain this repo and there are likely bugs.

The core idea of the game is based on the short story, The Lottery.

No AI was used in the making of this game.

# How to Play
Each player is given a random number. The player with the greatest number is chosen as the target for all other players to throw rocks at in a quick time event with SPACE (press once to start it movign and again to stop it). After all players have gone then the game repeats until somebody dies and the game ends.
